### **Fireweed** — Deterministic, Cryptographically Verifiable Memory for AI Agents
[![PyPI](https://img.shields.io/badge/pip_install-fireweed--mcp-3775A9?style=flat-square&logo=pypi&logoColor=white)](https://pypi.org/project/fireweed-mcp/)
[![GitHub Repo](https://img.shields.io/badge/Repo-fireweed--mcp-181717?style=flat-square&logo=github&logoColor=white)](https://github.com/Starksood/fireweed-mcp)
[![MCP Registry](https://img.shields.io/badge/MCP-Official_Registry-00A67E?style=flat-square)](https://registry.modelcontextprotocol.io/)
[![DEV Write-up](https://img.shields.io/badge/Article-DEV.to-0A0A0A?style=flat-square&logo=dev.to&logoColor=white)](https://dev.to/starksood/i-built-an-mcp-memory-server-where-code-not-the-model-decides-what-gets-stored-497j)
[![aiXiv](https://img.shields.io/badge/Preprint-aiXiv.260709.000003-B31B1B?style=flat-square)](https://aixiv.science/abs/aixiv.260709.000003)
[![OpenReview](https://img.shields.io/badge/Paper-OpenReview-8C1B13?style=flat-square)](https://openreview.net/pdf?id=mVgwFd5K0B)
[![Verification Bundle](https://img.shields.io/badge/Reproducibility-Fireweed__Fabric-2EA44F?style=flat-square&logo=github)](https://github.com/Starksood/Fireweed_Fabric)

Most agent memory puts the component that hallucinates in charge of the historical record. **Fireweed inverts that:** the LLM proposes a claim alongside a verbatim quote, and **four pure functions decide admission** (subject grounding, relation preservation, numeric fidelity, span containment). Zero LLM calls inside the server.

</td>
</tr>
<tr>
<td width="50%" valign="top">

#### 🔐 Core Cryptographic & Systems Guarantees
* **Adjudicated Writes:** Emits typed refusals (`REFUSED (asserts_more_than_evidence)`) detailing the claim, evidence, and required fix.
* **Verifiable Provenance:** Binds every fact to an exact source byte-range. `verify_receipts` re-hashes and re-slices so tampering fails loudly.
* **Redactable Merkle Receipts:** Merkle-tree binding over document parts allows erasing one subject while keeping third-party proofs intact.
* **Provable GDPR-Grade Erasure:** Per-subject AES-256-GCM crypto-shredding, durable tombstones against silent re-admission, and third-party verifiable **Ed25519** erasure certificates.

</td>
<td width="50%" valign="top">

#### 📐 Engineering & Published Research
* **Engine Specs:** ~10k LOC deterministic engine · **1,092 unit/property tests** · append-only hash-chained ledger · **zero runtime dependencies** · stdlib-only open format reader.
* **Paper:** *A Model-Independent Memory Substrate: Preserving an Agent's Account of a User Across LLM Swaps, Scales, and Families* (~0.8 semantic agreement across model families).
* **Stack:** `Python 3.9–3.13` · `Hand-rolled stdio JSON-RPC` · `SQLite` · `AES-256-GCM` · `Ed25519` · `GitHub OIDC Trusted Publishing`

</td>
</tr>

<td colspan="2">

> [!IMPORTANT]
> **Engineering Integrity & Public Retraction Note ([RETRACTION.md](https://github.com/Starksood/Fireweed_Fabric/blob/main/RETRACTION.md)):**
> During post-publication auditing, I discovered a scaled abstention benchmark reporting zero false assertions was actually measuring an unpopulated store (721/722 empty due to upstream extraction failure—where answering *"I don't know"* scores 100%). Rather than quietly patching it, I published a formal retraction with raw data and a one-line verification script. Decomposing the true recall revealed the admission gate finds stored answers **98.4%** of the time. Later, when a new optimization looked suspiciously good, I built an adversarial falsification corpus, watched it collapse a core invariant by 60 points, and reverted it.
